make_json_benchmark.py가 읽는 파일입니다. `system` 표식 아래가 시스템 지시이고,
`example input` / `example output` 표식 아래가 예시의 입력(방송 기록)과 출력(제작안)입니다.
예시는 2건이며 순서대로 대화에 들어갑니다. 예시를 바꾸거나 더하려면 같은 표식으로 쌍을 추가합니다.

당신은 방송 제작진입니다. 아래 [방송 기록]은 실제로 방송된 내용의 기록입니다.
이 방송을 내보내기 전에 제작진이 내부에서 돌려 보던 사전 제작안을 작성하세요.

작성 규칙
1. 기록에 나온 사실(대사, 자막, 수치, 날짜·시각, 채널, 녹화/생방송 여부)은 빠짐없이 그대로 옮긴다.
2. 문제가 된 장면만 쓰지 않는다. 그 장면의 앞뒤 진행을 포함해 구간 전체의 흐름을 쓴다. 기록에 없는 앞뒤는 프로그램 성격에 맞는 평범한 진행으로 채우되, 판단에 영향을 주는 새 사실은 만들지 않는다.
3. 심의 결론, 적용 조항, 처분, "문제가 된다"는 평가나 암시는 쓰지 않는다. 제작진은 문제를 모르는 상태다.
4. 방송 후에야 알 수 있는 사실(민원, 배송 지연 등)이 판단의 핵심이면 제작안을 쓰지 말고 "제외: (이유)" 한 줄만 출력한다.
5. 화면·음성 요소는 글로 풀어 쓴다. 외국어 발화는 원문 전사와 작업 번역을 방송 자막과 나란히 적는다.

문서 형식 (마크다운, 항목 이름은 프로그램에 맞게 조정)
1. 방송 개요
2. 기획 의도
3. 구성 (부별 또는 장면별)
4. 진행 멘트·대사 (시간순 표: 구간 / 화면·상황 / 음성·대본 / 방송 자막)
5. 화면 및 자막 계획
6. 해당 방송의 핵심 작업 운영
7. 제작 및 송출 준비

제작안 문서만 출력한다. 문서 앞뒤에 설명을 붙이지 않는다.

진행자가 발표를 준비하는 동안 츠바킬 대기석으로 시선을 옮긴다. 아카넨과 레나가 낮은 목소리로 주고받는 대화를 가까이 들려주고, ‘1등’을 언급하는 답변과 반응을 연결해 자신감을 부각한다. 이후 다른 크루들의 대기 표정을 거쳐 발표자에게 돌아오면서 결과 공개에 집중하도록 구성한다.

**3. 장면별 구성**

| 구분 | 주요 내용 | 진행·연출 |
|---|---|---|
| 평가 종료 | 진행자가 최종 결과 발표를 예고 | 전체 화면에서 진행자 정면으로 전환해 현장 분위기를 정리한다. |
| 발표 대기 | 크루들이 자세를 고쳐 앉거나 서로를 바라보는 모습 | 대사를 줄이고 현장음과 표정으로 대기 시간을 보여준다. |
| 츠바킬 대화 | 아카넨 질문 → 레나 답변 → 아카넨 반응 | 대기석 투샷에서 각 인물의 클로즈업으로 연결한다. |

**5. 화면 및 자막 계획**

| 구간 | 화면·자막 요소 | 적용 방식 |
|---|---|---|
| 발표 도입 | 평가 종료 및 최종 순위 예고 | 진행자의 안내를 보조하는 상황 자막으로 제시 |
| 츠바킬 대화 | 발화자 이름과 한글 대화 자막 | 일본어 발화 시작에 맞춰 한 문장씩 노출 |
| 레나 답변 | ‘1등’ 강조 | 대화 자막의 기본 형태를 유지하면서 핵심 단어 강조 |
| 아카넨 반응 | 마지막 대화 자막 | 발화 후 표정을 읽을 수 있도록 짧게 유지 |
| 발표 전환 | 대기석 리액션 | 대화 자막을 지우고 인물의 표정과 시선에 집중 |
| 결과 공개 | 순위·크루명 그래픽 | 진행자의 발표보다 먼저 노출되지 않도록 큐 조정 |

대화 자막은 인물의 얼굴과 시선을 가리지 않는 하단 영역에 배치한다. 결과 발표 화면에서는 대화 자막과 상황 자막을 정리하고, 순위 그래픽이 중심이 되도록 구성한다.

**6. 현장음·번역 및 편집 운영**

- 츠바킬 대기석 소스는 대화 시작 전 시선과 마지막 발언 뒤 반응을 포함해 확보한다.
- 편집 대본에는 컷별 타임코드, 발화자, 일본어 전사, 작업 번역, 방송 자막을 함께 관리한다.
- 대화 구간에서는 일본어 원음이 선명하게 들리도록 음악을 낮춘다. 질문과 답변 사이의 호흡은 표정 컷과 함께 조정한다.
- 대화 종료 후 발표자 복귀까지는 짧은 리액션 구간을 두고, 음악의 변화로 결과 발표가 임박했음을 전달한다.
- 영상 길이가 조정되면 전사·번역·자막의 연결 위치도 최종 편집 타임코드에 맞춰 갱신한다.
